# CalMate

CalMate is a calorie and nutrition tracker for logging meals and workouts, tracking daily calorie and macro goals, and reviewing progress over time. Data is stored in your browser using `localStorage`.

## Features

- Log meals and workouts manually or describe an entry for AI-assisted parsing.
- Track daily calorie intake, calories burned, and meal macros.
- Set personal calorie and macro goals, with an AI macro calculator.
- Review daily details, history, and weekly summaries.
- Use light or dark theme, with installable PWA support.
